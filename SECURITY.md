# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities using GitHub's private reporting feature. Do not open public issues for security vulnerabilities. We will respond within 48 hours.

## Scope

The scope of this security policy covers the instruction package and the synthetic fixtures included in this repository.

## Third-Party Content Acknowledgment

This tool is designed to test systems only when explicit authorization has been granted by the owner. Do not use this skill against systems without explicit authorization.

## Fixture Safety

The fixtures provided in this repository use synthetic data only and run on in-memory SQLite databases. They do not contain real credentials or interact with any external systems.
